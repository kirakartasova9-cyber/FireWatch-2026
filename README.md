# FireWatch AI

FireWatch AI — русскоязычный учебный прототип для демонстрации мониторинга лесных пожаров. Все станции и измерения демонстрационные: сайт **не обнаруживает реальные пожары** и не предназначен для принятия решений о безопасности.

## Как открыть

В Replit откройте предпросмотр приложения **FireWatch AI**. API-сервер и сайт запускаются настроенными рабочими процессами; SQLite-файл создаётся автоматически при первом запуске API. Отдельно устанавливать базу данных не нужно.

## Что можно делать

- Просматривать сводку, станции на карте, графики измерений и журнал предупреждений.
- Переключать обычный и опасный сценарии; браузерный симулятор отправляет показания в API каждые 15 секунд, а сервер проверяет и сохраняет их, рассчитывает риск и создаёт предупреждения.
- Приостанавливать и сбрасывать симуляцию.
- Добавлять, редактировать и удалять станции.
- Отмечать предупреждения обработанными.

Демонстрационная база хранится в `data/firewatch.sqlite`. При ручной очистке файла база и исходные учебные станции создадутся заново при следующем запуске API.
